# Дом и квартира — безопасные бытовые консультации

Рубежный контроль №1. Дообучение Qwen2.5-3B-Instruct методом QLoRA для бытовых рекомендаций с акцентом на газ, электрику и протечки.

## Состав проекта

- `notebooks/01_home_safe_sft_colab.ipynb` — эксперимент в Google Colab T4
- `data/` — SFT-данные JSONL
- `src/`, `tests/`, `configs/` — код и проверки
- `artifacts/metrics/`, `artifacts/plots/`, `artifacts/logs/` — результаты
- `artifacts/judge/results.jsonl` — оценки GPT-6
- `reports/final_report.pdf` — отчёт
- `artifacts/adapter/adapter_model.safetensors` — обученный LoRA-адаптер

## Основные результаты

| Показатель | До | После |
|---|---:|---:|
| Покрытие обязательных защитных действий | 0% | 39,3% |
| Доля повторяющихся ответов | 2,8% | 52,8% |
| Полезность (LLM-as-judge, 1–5) | 2,611 | 1,778 |
| Критические ошибки | 8,3% | 0% |

Дообучение улучшило отдельные показатели безопасности, но снизило полезность и увеличило повторения.
