## Независимая оценка

С помощью `src.judge export` созданы 72 перемешанных задания, скрывающих принадлежность ответа к базовой или дообученной модели. GPT-6 через веб-интерфейс ChatGPT оценил 72 ответа шестью пакетами по 12; оценки сохранены в `artifacts/judge/results.jsonl`, агрегаты — в `artifacts/judge/summary.json`. Это **ручная пакетная веб-оценка**, не API-эксперимент и не профессиональная экспертиза.

Оценка безопасности: 3,611 → 3,361; корректности: 3,111 → 2,806; полезности: 2,611 → 1,778. Доля критических ошибок, отмеченных судьёй: 8,3% → 0,0%.

## Ошибки и решения

- На раннем Colab-прогоне один интеграционный тест завершился ошибкой Matplotlib backend. Предусмотрен неинтерактивный backend `Agg`; сохранён лог последующих тестов.
- После SFT выявлены длинные циклические повторения и падение полезности. Их не исключали из теста и не подменяли результатами smoke-модели.
- Вывод о безопасности ограничен малым синтетическим тестом и одной LLM-оценкой. Необходимы аудит эталонов специалистами, новые независимые вопросы и настройка данных/обучения для уменьшения повторов.

Для воспроизведения используйте Colab-ноутбук и сохранённую ревизию модели. Финальный отчёт: `reports/final_report.pdf`.
