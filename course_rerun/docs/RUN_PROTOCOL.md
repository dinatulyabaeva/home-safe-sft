# Протокол эксперимента

1. Валидировать schema и непересечение `qa_id`.
2. Зафиксировать модель, ревизию, seed, decoding params и версии библиотек.
3. Сгенерировать baseline на validation и bench.
4. Рассчитать формат и метки на validation.
5. Запустить QLoRA только на train, использовать val для выбора лучшего checkpoint.
6. Сгенерировать SFT ответы на тех же validation и bench вопросах с теми же параметрами.
7. Рассчитать метрики validation.
8. Экспортировать bench задания судье без доступа к модели/источнику ответа.
9. Судья оценивает каждый rubric criterion true/false и объясняет решение. Рассчитать сумму points для каждого ответа и среднее по 30 вопросам.
10. Сохранить все outputs, logs, hashes, config и обновить отчёт.

Не обучаться на val или bench; не подбирать параметры по bench; не подменять отсутствующие оценки нулями.
