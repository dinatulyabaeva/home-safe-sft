# Дом и квартира — безопасные бытовые консультации

**Рубежный контроль №1.** Эксперимент по SFT-дообучению `Qwen/Qwen2.5-3B-Instruct` методом QLoRA для русскоязычных консультаций о газе, электричестве, протечках и бытовых вопросах.

## Результаты эксперимента

Бейзлайн, пробная генерация, QLoRA-обучение на Tesla T4, повторная генерация и сравнение выполнены. Сохранены фактические предсказания, обученный LoRA-адаптер, метрики, графики и журналы. Отдельная модель-судья GPT-6 оценила 72 обезличенных ответа (36 пар) через веб-интерфейс ChatGPT.

| Показатель | До SFT | После SFT |
|---|---:|---:|
| Покрытие обязательных защитных действий (высокий риск) | 0,0% | 39,3% |
| Полное выполнение чек-листа (высокий риск) | 0,0% | 0,0% |
| Повторяющиеся предложения | 2,8% | 52,8% |
| Ответ достиг лимита токенов | 2,8% | 52,8% |
| Безопасность, GPT-6 (1–5) | 3,611 | 3,361 |
| Корректность, GPT-6 (1–5) | 3,111 | 2,806 |

| Критические ошибки по оценке GPT-6 | 8,3% | 0,0% |

**Вывод:** дообучение увеличило покрытие защитных действий, но ухудшило общую полезность, корректность и стабильность текста. Падение числа критических ошибок по одной LLM-оценке не доказывает безопасность модели.

## Данные и обучение

192 синтетических примера в четырёх темах: газ, электричество, вода и обычные бытовые задачи. Разбиение по семействам сценариев: train 40, validation 12, test 12; в каждом семействе три перефразировки. Между выборками нет пересечения `family_id`. Общие правила безопасности между сценариями остаются семантически близкими.

Параметры QLoRA: 4-бит NF4 double quantization, rank 8, alpha 16, dropout 0,05, learning rate 1e-4, три эпохи, micro-batch 1, gradient accumulation 8, FP16, gradient checkpointing. `train_loss=1.3106`, `eval_loss=1.0040`; продолжительность обучения по журналу — около 413 секунд. Использовалась Tesla T4. Точная ревизия базы и версии библиотек сохранены в `artifacts/adapter/experiment.json` и `artifacts/logs/runtime.json`.

Модель обучалась только на токенах ответа ассистента. Бейзлайн и адаптер сравнивались на одинаковом наборе тестовых вопросов, с одинаковым системным промптом и настройками декодирования.

## Как запустить

1. Откройте [ноутбук](notebooks/01_home_safe_sft_colab.ipynb) в Google Colab, выберите **GPU T4** и последовательно выполняйте ячейки. Для нового независимого запуска используйте отдельную копию проекта и не перезаписывайте опубликованные результаты.
2. Для локального окружения Python 3.12 установите зависимости из `requirements-torch.txt` и `requirements.txt`, затем запустите:

```bash
python -m unittest discover -s tests -v
python -m src.local_checks
python -m src.pipeline prepare
python -m src.pipeline generate --split demo_prompts --out artifacts/demo_baseline.jsonl
python -m src.pipeline generate --split test
python -m src.pipeline train --smoke
python -m src.pipeline train
python -m src.pipeline generate --split test --adapter artifacts/adapter
python -m src.evaluate
python -m src.judge export
python -m src.judge summarize
```

Существующие файлы результатов принадлежат завершённому запуску: для повторения используйте **отдельную копию**, поскольку код защищает фиксированные эксперименты от несовместимой перезаписи. Для новой независимой оценки понадобятся действительные ответы отдельного судьи; опубликованные оценки воспроизводят уже проведённую ручную процедуру.

## Ограничения

- Синтетические эталоны не проходили независимую профессиональную проверку (`human_review_status=pending`); рекомендации не заменяют аварийные службы и квалифицированных специалистов.
- Регулярные выражения автоматической проверки имеют известные ложные срабатывания; метрика покрытия действий не равна гарантии безопасности.
- Один небольшой тест, один seed и один LLM-судья не подтверждают переносимость результатов. При пакетной веб-оценке возможна вариативность судьи.
- Полезность и связность ответов после SFT ухудшились: эту проблему следует устранять в следующей итерации.

Подробные решения, ограничения и библиография — [журнал эксперимента](docs/RUN_NOTES.md), [карточка данных](data/DATA_CARD.md), [источники](docs/SOURCES.md). Перед повторным использованием базовой модели проверьте условия её лицензии.
