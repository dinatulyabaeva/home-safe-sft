
## Результат локального аудита формата эталонов

Проверка строгих требований формата (2–4 предложения до блока «Что сделать», 2–5 нумерованных шагов, не более 150 слов, без Markdown-заголовков, четыре завершающие метки в заданном порядке) показала:

- train: 49 из 50 ответов проходят проверку;
- validation: 20 из 20 ответов проходят проверку.

Единственный train-ответ, не прошедший проверку, — `home-sft-public-train-039`: перед блоком «Что сделать» находится одно предложение, хотя спецификация требует 2–4. Исходный эталон не изменялся; это ограничение переданного набора данных, которое следует отметить в отчёте.
